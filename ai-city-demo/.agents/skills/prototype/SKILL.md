# Prototype

프로토타입은 질문 하나에 답하기 위한 버릴 코드다. 실제 앱에 들어갈 mock-first 구현과 구분한다.

- 상태 전이와 타이밍을 검증할 때는 `LOGIC.md`를 읽는다.
- 서로 다른 레이아웃을 비교할 때는 `UI.md`를 읽는다.
- 어느 쪽인지 모호하면 추측하지 않고 확인한다.

공통 규칙:

1. 파일과 화면에 프로토타입임을 표시한다.
2. 실제 데이터와 비밀정보에 연결하지 않는다.
3. 질문에 필요하지 않은 기능과 마감을 추가하지 않는다.
4. 결정 후 실제 코드에는 결정만 다시 구현한다.
5. 프로토타입 스냅샷과 결정 근거는 `docs/designs/`에 남긴다.
