# 완료 전 검증

완료 주장을 하기 전에 이번 변경을 증명하는 검증을 직접 실행한다.

## 최소 검증

- 코드 변경: `npm run typecheck`
- 빌드 영향: `npm run build`
- UI 변경: localhost에서 실제 렌더링과 콘솔 오류 확인
- 상호작용 변경: 해당 마우스·터치 시나리오 재현
- 에셋 변경: 오프라인 상태에서 이미지·영상 경로 확인

## 완료 보고

- 실행한 명령과 결과
- 브라우저에서 확인한 흐름
- 자동화로 확인할 수 없어 실제 포터블 모니터에서 확인해야 하는 항목

이전 실행 결과나 코드만 보고 완료를 주장하지 않는다.
