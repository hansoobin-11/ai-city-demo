## 이번 응답에서 할 일

1. 기존 데모 HTML 2개를 비교해 다음 항목만 분석하세요.
   - 도시 메인 화면의 시각 구조
   - 5개 영역과 핫스폿의 배치

   - 새 프로젝트로 재사용할 수 있는 로컬 에셋 목록
2. 현재 Vite + Vanilla TypeScript 골격을 유지하는 **승인 게이트 1 계획**을 작성하세요.
   - 범위: 프로젝트 실행 확인 + 도시 메인 화면 정적 이관
   - 제외: 상세 화면, 자동 카드 순환, 영상, 외부 데모 연결, 추가 카피 작성
3. 아래 형식으로 보고하세요.

   - 유지할 디자인 요소

   - 에셋 이관 목록과 출처
   - 검증 방법(1920×1080 포함)
   - 사용자에게 확인받아야 할 모호한 사항
