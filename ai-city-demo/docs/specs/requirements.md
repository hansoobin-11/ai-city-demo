# AI CITY 전시 데모 요구사항

## 목적

포터블 터치 모니터에서 SPACEBANK AI CITY의 5개 영역을 직관적으로 소개하고, 준비된 영상 또는 외부 데모로 연결한다.

## 화면 범위

1. 인트로 없이 도시 메인 화면으로 진입
2. 5개 영역의 자동 순환 카드
3. 핫스폿 선택 시 공통 상세 화면
4. 자료가 있을 때만 영상 및 데모 버튼 표시
5. 도시 화면 복귀와 이전·다음 솔루션 이동

## 입력

- 터치 한 번으로 상세 진입
- 마우스 hover는 카드 미리보기만 제공
- 마우스 클릭과 펜 입력 지원
- 사용자 입력 시 자동 순환 정지

## 실행 환경

- 기준 해상도 1920×1080
- Windows PC와 포터블 터치 모니터
- Edge 또는 Chrome
- 인터넷 없이 로컬 콘텐츠 동작
- localhost 기반 실행

## 콘텐츠 경계

- 소개 대상은 HUMAN CARE, SAFETY, INFRASTRUCTURE, ROBOTICS, SMART ROAD 5개 영역이다.
- 제품화 여부와 적용 상태는 승인된 라벨로 구분한다.
- 도시혁신대상 PPT는 방향 참고용이며 화면 설명 범위를 확장하는 근거로 사용하지 않는다.
- 외부 데모 URL과 로그인 정보는 사용자가 직접 제공한다.

## 승인 게이트

1. 프로젝트와 도시 메인 화면 이관
2. 입력과 자동 카드 순환
3. 공통 상세 화면
4. 5개 콘텐츠와 에셋
5. 영상·외부 데모
6. 포터블 모니터 QA
