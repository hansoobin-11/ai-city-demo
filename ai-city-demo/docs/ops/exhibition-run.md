# 전시 실행 절차 (우분투)

이 문서는 **읽는 문서**다. 자동으로 실행되는 스크립트는 없다.
현장에서 이 순서대로 따라 하면 된다.

---

## 준비물

- USB 하나 (여유 1GB 이상)
- USB에 담을 것: `dist` 폴더 **하나뿐**

`dist`는 빌드 결과물이며 아래 6개 파일로 이루어진다. 총 5.0MB.

```
dist/
├── index.html
├── assets/
│   ├── city.jpg                    도시 배경
│   ├── logo.png                    스페이스뱅크 로고
│   ├── index-*.css                 화면 스타일
│   └── index-*.js                  화면 구성 코드
└── fonts/
    └── PretendardVariable.woff2    본문 서체
```

`node_modules`, `src`, `package.json` 등은 **가져갈 필요 없다.**
빌드는 개발 PC(윈도우)에서 끝났고, 우분투에서는 아무것도 설치하지 않는다.

### USB에 담는 법

윈도우에서 `dist` 폴더를 통째로 복사해 USB에 붙여넣으면 끝이다.
폴더 이름은 바꿔도 되지만, 안쪽 구조(`assets`, `fonts` 폴더)는 그대로 둬야 한다.

---

## 전시 당일 절차

### 1. USB를 꽂고 `dist` 폴더를 연다

파일 관리자에서 USB를 열고 `dist` 폴더 안으로 들어간다.
`index.html`이 보이는 위치까지 들어가야 한다.

> **주의**: `index.html`을 더블클릭하지 않는다. 화면이 검게 나온다.
> 이유는 이 문서 맨 아래 "왜 파일을 직접 열면 안 되나"에 적어 두었다.

### 2. 그 폴더에서 터미널을 연다

폴더 안 빈 공간에서 **우클릭 → "터미널에서 열기"**
(영문 환경이면 "Open in Terminal")

이렇게 열면 경로를 칠 필요가 없다. 이미 `dist` 폴더에 들어간 상태로 터미널이 뜬다.

> 우클릭 메뉴에 그 항목이 없다면 → "문제가 생겼을 때" 1번 참고

### 3. 아래 한 줄을 입력하고 Enter

```
python3 -m http.server 8080 --bind 127.0.0.1
```

**성공하면 이렇게 나온다:**

```
Serving HTTP on 127.0.0.1 port 8080 (http://127.0.0.1:8080/) ...
```

이 줄이 보이면 된 것이다. 커서가 멈춘 채로 있는 게 정상이다.
**이 터미널 창은 닫지 말고 그대로 둔다.** (최소화는 해도 된다)

### 4. Chrome을 열고 주소창에 입력

```
localhost:8080
```

도시 화면이 나오면 성공이다.

### 5. F11을 눌러 전체화면

브라우저 주소창과 탭이 사라지고 화면이 꽉 찬다.

---

## 끝낼 때

1. F11로 전체화면 해제 → 브라우저 닫기
2. 터미널 창에서 **Ctrl + C** → 터미널 닫기

시스템에 남는 것은 없다. USB를 뽑으면 끝이다.

---

## 문제가 생겼을 때

### 1. 우클릭에 "터미널에서 열기"가 없다

키보드로 **Ctrl + Alt + T** 를 눌러 터미널을 연다.
터미널에 `cd ` (cd 뒤에 한 칸 띄우기)를 치고,
**`dist` 폴더를 터미널 창 안으로 끌어다 놓는다.** 경로가 자동으로 입력된다.
Enter를 누른 뒤 3번 절차로 넘어간다.

### 2. `Address already in use` 라고 나온다

포트 번호가 이미 쓰이고 있다는 뜻이다. **숫자만 바꾸면 된다.**

```
python3 -m http.server 8081 --bind 127.0.0.1
```

브라우저 주소도 같은 숫자로 맞춘다 → `localhost:8081`
8081도 안 되면 8082, 8083으로 계속 올려도 된다.

### 3. `python3: command not found` 라고 나온다

그 PC에 python3이 없다는 뜻이다. **전시 전에 반드시 확인해야 할 항목이다.**
현장에서 이 문제를 만나면 설치할 방법이 없으니, 아래 "사전 확인"을 먼저 하자.

### 4. 브라우저에 아무것도 안 나온다 / 검은 화면

- 터미널 창이 아직 떠 있고 `Serving HTTP on ...` 줄이 살아 있는지 확인
- 주소를 정확히 `localhost:8080` 으로 쳤는지 확인 (`https://` 붙이지 않는다)
- 터미널에 빨간 글씨로 `404` 가 찍힌다면 → `dist` 폴더가 아닌 다른 폴더에서 터미널을 열었을 가능성. `index.html`이 있는 폴더인지 확인

### 5. 글꼴이 이상하게 보인다

`fonts` 폴더가 같이 복사되지 않았을 때 생긴다. USB의 `dist` 안에
`fonts/PretendardVariable.woff2`가 있는지 확인한다.

---

## 사전 확인 (전시 전에 한 번은 꼭)

**현장에서 처음 꽂아보는 것은 위험하다.** 실제 전시에 쓸 그 우분투 PC에서
아래를 미리 확인한다.

| 확인할 것 | 방법 | 통과 기준 |
|---|---|---|
| python3 설치 여부 | 터미널에 `python3 --version` | `Python 3.x.x` 가 나옴 |
| USB 자동 인식 | USB를 꽂아본다 | 파일 관리자에 뜸 |
| 우클릭 터미널 메뉴 | 폴더에서 우클릭 | "터미널에서 열기"가 보임 |
| 전체 절차 | 위 1~5번을 그대로 | 도시 화면이 뜸 |
| 전체화면 | F11 | 잘림·여백 없이 꽉 참 |
| 해상도 | 디스플레이 설정 | 1920×1080 |

### 브라우저는 Chrome을 쓴다

전시 PC에 **Chrome이 설치되어 있는 것을 확인했다.** Chrome으로 열면 된다.

현재 빌드는 Chrome과 같은 엔진(Chromium)에서 검증을 마쳤으므로 추가 확인 사항은 없다.

> 우분투는 Firefox가 기본 브라우저로 지정되어 있는 경우가 많다.
> 4번 절차에서 주소를 넣었을 때 Firefox가 열렸다면, 창을 닫고
> **Chrome을 먼저 실행한 뒤** 그 주소창에 `localhost:8080` 을 입력한다.
> (Firefox는 검증하지 않았다)

---

## 왜 파일을 직접 열면 안 되나

`index.html`을 더블클릭하면 브라우저가 `file://` 방식으로 연다.
이 방식에서는 브라우저 보안 정책상 서체와 화면 구성 코드를 읽지 못해
**검은 화면만 나온다.** 고장이 아니라 원래 그렇게 동작한다.

3번 절차의 명령은 이 문제를 없애는 것이다.
그 명령이 하는 일은 **"이 폴더의 파일을 브라우저가 읽을 수 있게 내놓는다"**가 전부다.

- 설치하는 것 없음
- 그 폴더 밖은 건드리지 않음
- 인터넷 연결 불필요 (모든 파일이 USB 안에 있다)
- 터미널을 닫으면 완전히 종료

오타를 쳐도 에러 한 줄 나오고 끝이다. 다시 치면 된다.

---

## 요약 카드 (현장용)

```
1. USB → dist 폴더 열기
2. 빈 공간 우클릭 → 터미널에서 열기
3. python3 -m http.server 8080 --bind 127.0.0.1
4. Chrome 주소창 → localhost:8080
5. F11

끝낼 때: 터미널에서 Ctrl + C
포트 오류 시: 8080 → 8081 로 바꾸고 주소도 함께 변경
```
