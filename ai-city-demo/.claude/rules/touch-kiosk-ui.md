# 터치 전시 UI 규칙

1. 호버는 마우스용 보조 효과다. 모든 핵심 기능은 터치 한 번으로 사용할 수 있어야 한다.
2. 장치 전체를 `maxTouchPoints`로 분기하지 말고 각 `PointerEvent.pointerType`을 사용한다.
3. 터치 대상은 손가락으로 누르기 충분한 크기와 간격을 확보한다.
4. 버튼과 핫스폿에는 의도에 맞는 `touch-action`을 적용한다.
5. 자동 카드 순환은 사용자 입력 즉시 멈추고, 복귀 후 명시된 시간에 다시 시작한다.
6. 전환 중 중복 입력을 차단하고 빠른 연속 탭으로 타이머가 중첩되지 않게 한다.
7. 비디오와 외부 데모는 조건부로만 노출한다. 빈 버튼과 깨진 플레이스홀더를 만들지 않는다.
8. `file://` 직접 실행을 완료 조건으로 삼지 않는다. localhost와 실제 전시 브라우저에서 검증한다.
