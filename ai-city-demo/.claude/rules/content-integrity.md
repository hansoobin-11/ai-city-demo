# 솔루션 콘텐츠 무결성

1. 제품 기능, 적용 상태, 고객사, 수치, 인증은 제공된 자료에서 직접 확인 가능한 내용만 사용한다.
2. 완제품, 현장 적용 사례, 데모 가능, 맞춤형 구축을 서로 바꾸어 표현하지 않는다.
3. 도메인 판단이 필요한 카피와 분류를 인접 자료에서 추론해 채우지 않는다. 비워두거나 플레이스홀더로 표시하고 확인받는다.
4. 데모 URL과 로그인 정보는 추측하지 않는다.
5. 아이디, 비밀번호, 토큰 등 비밀정보를 소스, 로그, 채팅에 넣지 않는다.
6. 사용자가 확정한 문구와 판단 권한을 기술적 편의를 이유로 되돌리지 않는다.
