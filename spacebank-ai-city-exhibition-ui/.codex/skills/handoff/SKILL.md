# Handoff

파일을 만들지 않고 다음 작업에 그대로 붙여넣을 수 있는 한국어 마크다운을 작성한다.

1. 브랜치, 파일, 실행 상태처럼 확인 가능한 내용은 실제로 확인한 뒤 적는다.
2. 계획서나 스펙에 이미 있는 내용은 반복하지 않고 경로만 남긴다.
3. 완료, 진행 중, 다음 할 일, 하지 말아야 할 것만 압축한다.
4. API 키, 자격증명, 개인정보는 포함하지 않는다.
5. 사용자가 다음 작업의 초점을 지정했다면 그 순서에 맞춘다.

기본 형식:

```markdown
## 배경

## 현재 상태 (직접 확인함)
- 완료:
- 진행 중:

## 다음에 할 것
1.

## 하지 말 것
-

## 참고
-
```

원본: 개인화 Claude 스킬 `personalized/handoff`. Codex에서는 명시적 호출 전용 정책을 `agents/openai.yaml`에 둔다.
