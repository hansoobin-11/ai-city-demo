# Prototype

프로토타입은 질문 하나에 답하기 위해 만들고 방향이 정해지면 폐기하는 코드다. 실제 기능을 mock 데이터로 먼저 만드는 작업과 구분한다.

- 상태 전이, 비즈니스 로직, 데이터 구조를 검증할 때는 [references/logic.md](references/logic.md)를 읽는다.
- 서로 다른 화면 레이아웃을 비교할 때는 [references/ui.md](references/ui.md)를 읽는다.
- 어느 유형인지 두 가지 이상으로 해석되면 구현 전에 사용자에게 확인한다.

공통 원칙:

1. 이름과 화면 설명에서 폐기 전제 프로토타입임을 드러낸다.
2. 실제 DB나 외부 mutation에 연결하지 않는다.
3. 질문에 필요한 최소 범위만 구현한다.
4. 검증이 끝나면 결정만 실제 구현에 흡수하고 스냅샷은 `docs/designs/`에 남긴다.
5. 도메인 판단이 필요한 값은 추측해 채우지 않고 이해관계자가 직접 판단할 수 있게 만든다.

원본: 개인화 Claude 스킬 `personalized/prototype`. Codex에서는 명시적 호출 전용 정책을 `agents/openai.yaml`에 둔다.
