# UI 프로토타입

구조적으로 다른 UI 변형을 비교할 때 사용한다.

- 기본 변형 수는 3개이며 5개를 넘기지 않는다.
- 기존 페이지가 있으면 같은 라우트에서 `?variant=`로 렌더링만 바꾼다.
- 기존 페이지가 없을 때만 명확히 prototype으로 표시된 임시 라우트를 만든다.
- 색만 다른 안이 아니라 정보 구조와 레이아웃이 다른 안을 만든다.
- 하단 전환 바와 방향키로 변형을 바꾸고 URL에 선택 상태를 유지한다.
- 입력 필드에 포커스가 있을 때 방향키를 가로채지 않는다.
- 실제 mutation에는 연결하지 않는다.
- 선택이 끝나면 승자안을 정식 코드로 다시 구현하고 전체 비교본은 `docs/designs/`에 보관한다.
