# 로직 프로토타입

상태 전이, 비즈니스 로직, 데이터 구조에 관한 질문을 검증할 때 사용한다.

- 화면 상단에 검증할 질문을 한 문단으로 표시한다.
- 로직은 DOM과 분리된 순수 리듀서, 상태 머신, 순수 함수 또는 작은 모듈로 작성한다.
- 개발자가 아닌 이해관계자가 더블클릭해 사용할 수 있는 단일 HTML을 기본으로 한다.
- 현재 상태, 자유 조작 버튼, 정상·예외·금지 사례 시나리오를 눈에 보이게 제공한다.
- 기본적으로 메모리 상태만 사용하고 서버·프레임워크·DB를 붙이지 않는다.
- 검증된 로직만 실제 코드로 다시 구현하고 데모 HTML은 `docs/designs/`에 보관한다.
