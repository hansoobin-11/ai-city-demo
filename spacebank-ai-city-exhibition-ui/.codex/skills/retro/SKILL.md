# Retro

코드 품질이 아니라 에이전트가 일한 방식을 검토한다. 결과를 채팅에서 읽을 수 있는 자연스러운 한국어로 제시하고 규칙 파일을 바로 수정하지 않는다.

다음 순서로 개선 후보를 찾는다.

1. 반복 교정 패턴과 기존 규칙의 트리거 누락
2. 파일과 맥락을 찾는 탐색 비용
3. 자동 검증 공백
4. 규칙과 스킬의 실제 환경 불일치
5. 지침 파일 비대화와 중복
6. 반복적이거나 불필요한 도구 호출
7. 접근하지 못해 확인하지 못한 정보

후보는 반복 횟수와 되돌리기 비용 순으로 정리한다. 새 규칙을 제안할 때는 발동 시점을 `X가 일어나면 Y한다` 형태로 명시한다. 실제 반영 여부는 사용자가 결정한다.

원본: 개인화 Claude 스킬 `personalized/retro`. Codex에서는 명시적 호출 전용 정책을 `agents/openai.yaml`에 둔다.
