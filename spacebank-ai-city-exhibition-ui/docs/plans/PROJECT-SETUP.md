# SPACEBANK AI CITY 전시 UI 프로젝트 전환

## 목적

기존 단일 오프라인 HTML 프로토타입을 작업용 프로젝트 구조로 옮기고, 네 화면 동기 재생과 화면별 단독 렌더링을 안정적으로 관리한다.

## 초기 구조

- `src/screens/`: TOP, LEFT, CENTER, RIGHT 화면 구현
- `src/timeline/`: 공통 장면·시간축·재생 상태
- `src/router/`: 창 실행과 동기 제어
- `public/assets/`: 이미지, 로고, 폰트, 영상
- `offline/`: 전시장용 오프라인 빌드
- `docs/designs/`: 비교용 UI 프로토타입 스냅샷
- `.codex/skills/`: 이 프로젝트에서 사용하는 개인화 Codex 스킬

## 첫 구현 체크포인트

1. 현재 수동재생 v4의 장면·타이밍·에셋 목록을 추출한다.
2. 공통 시간축과 화면 렌더러를 분리한다.
3. 화면별로 자기 화면만 렌더링하게 만든다.
4. 통합 라우터에서 네 창의 재생·일시정지·처음으로를 동기 제어한다.
5. 네 화면 동시 실행 성능을 확인한다.
6. 밝은 전시장 표시 모드를 추가한다.
7. 오프라인 실행본을 생성한다.

현재 HTML은 기준 동작을 보존하기 위한 레거시 레퍼런스로 취급하고, 초기 전환 단계에서는 수정하지 않는다.
