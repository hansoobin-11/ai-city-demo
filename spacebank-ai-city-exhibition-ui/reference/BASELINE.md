# 기존 전시 UI 기준본

이 폴더는 프로젝트 구조 전환 과정에서 기존 디자인과 동작을 비교하기 위한 수정 금지 기준본이다.

## 실행

`baseline/00_통합라우터 (수동재생).html`을 더블클릭한다. 복사된 기준본 안에서 실행되도록 원본 라우터의 파일 상대경로만 `./`로 변경했으며, UI와 재생 로직은 수정하지 않았다.

## 기준 파일

- `baseline/AI CITY 메인 인트로 (오프라인용 v4 · 수동재생).html`: 현재 4면 전시 UI 기준 구현
- `baseline/00_통합라우터 (수동재생).html`: 확장 디스플레이 수동 배치 및 동시 재생 기준
- `screenshots/4면배치.png`: 전체 배치 기준
- `screenshots/TOP.png`: TOP 화면 기준
- `screenshots/화면1_CENTER.png`: CENTER 화면 기준
- `screenshots/화면2_LEFT.png`: LEFT 화면 기준
- `screenshots/화면3_RIGHT.png`: RIGHT 화면 기준

## 유지할 디자인과 구성

- A01 → A02 각 영역 → A02 5개 신호 완성 → A03 중앙 연결 → OUTRO의 장면 순서
- TOP과 하단 3면의 기본 배치 및 카피 구조
- 하단 LEFT·CENTER·RIGHT의 하나로 이어지는 도시 파노라마
- 센서 위치, 점등 순서, 중앙으로 수렴하는 라인 구성
- 수동 라우터에서 네 창을 열고 모니터에 배치한 뒤 동시에 재생하는 운영 흐름
- 기존 브랜드 컬러, 타이포그래피 방향, 도시 야간 이미지 분위기

## 변경 가능한 범위

- 화면별 단독 렌더링을 통한 성능 최적화
- 공통 시간축과 동기 재생 구조 개선
- 밝은 전시장용 명도·대비·글로우 보정
- 하단 3면 사이의 색감 보정
- 타이밍과 카메라 움직임의 세부 조정

구조 전환 중 시각적 차이가 생기면 먼저 이 기준본과 같은 시점의 화면을 나란히 비교한다. 명시적인 디자인 변경 요청이 없으면 기준본의 구성을 우선한다.
